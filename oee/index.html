Arquitectura de datos

Grafana SQL Server (red TATA) → agente interno → Supabase (datos protegidos) → dashboard GitHub Pages. El mismo agente puede enviar un reporte a Power Automate para Teams y Outlook. Producción, ocupación y eficiencia son indicadores distintos; OEE completo requiere disponibilidad, rendimiento y calidad validados.
